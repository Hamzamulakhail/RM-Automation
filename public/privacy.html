Privacy Policy

Effective date: 2026-01-01

RM Automation is a private administrative automation tool operated by the owner of this deployment to publish scheduled photos, videos, and captions from designated Google Drive folders to authorized Facebook Pages.

Information We Process

  • Facebook User ID, display name, and Page IDs/names retrieved via Facebook Login with your explicit consent (pages_show_list, pages_manage_posts, pages_read_engagement).
  • Encrypted Facebook User and Page access tokens stored in Cloudflare D1 using AES-256-GCM encryption.
  • Google Drive folder IDs, file metadata, and caption text read from folders explicitly shared with the configured Google Service Account.
  • Operational schedules, post history, and diagnostic event logs (automatically pruned after 30 days).

How Data Is Used & Shared

Data is used solely to publish content to your selected Facebook Pages and monitor delivery status. No data is sold, rented, or shared with third parties other than Meta Graph API and Google Drive API as required to perform scheduled posting.

Security

All access tokens are encrypted at rest and never exposed to the browser after authorization. Access to the administration panel is protected by a password and signed HttpOnly session cookies.

Data Deletion

You may revoke access and delete stored accounts, Pages, and encrypted tokens at any time from the admin panel or by following the instructions on the Data Deletion page.
